# Intuitive_Physics

The primary objective of this project is to explore intuitive physics, which encompasses an understanding of
fundamental physical principles, such as object permanence (Lake et al., 2017). Intuitive physics research
has been approached from diverse perspectives and domains, including cognitive science (Lake et al., 2017;
Battaglia et al., 2013), developmental psychology (Piloto et al., 2022), and deep learning engineering (Lerer
et al., 2016). Prominent contributions include Battaglia et al.'s Intuitive Physics Engine (IPE), which
leverages Bayesian cognitive modeling to answer questions like "Will it fall?" and "In which direction?"
(Battaglia et al., 2013), and also Piloto et al.'s study highlighting the gap in intuitive physics capabilities
between humans and AI systems (Piloto et al., 2022).


Despite the diversity of approaches, existing studies primarily rely on traditional deep learning methods,
such as Convolutional Neural Networks (CNNs) for stability prediction (Lerer et al., 2016), without
leveraging latent space disentanglement for intuitive physics. This project proposes training a Variational
Autoencoder (VAE) to disentangle the latent space, enabling controlled exploration of physical dynamics in
synthetic block-stacking scenarios. The aim is to model intuitive physics by incorporating spatial and
temporal dynamics, disentangling latent factors for key attributes such as velocity, position, and time.
